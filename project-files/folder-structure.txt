Cable Car 3D Simulation: Project Folder Structure

Root Directory:

- assets/ — Assets used to create the scene, such as the 3D models we will be using.

- build/ — Generated build files and compiled outputs

- framework/ — Reusable graphics framework

- project-files/ — Project planning and documentation we will be referring to

- resources/ — Resources that would loaded by the application, such as models, textures, cubemap images, and scene configuration files (assets and this are similar in functionality, so prefer using this going forward).

- shaders/ — GLSL shader programs used for rendering.

- src/ — C++ source code implementing the application.

    - main.cpp — This will be the application entry point.

    - application.cpp — Main application logic, including initialization, updates, rendering, and input handling, depending on the implementation.


Team Guidelines:

- Keep C++ source code in src/ and GLSL shaders in shaders/.

- Do not commit generated build outputs unless required.

- Ensure that the variable names are meaningful and convey something valuable for others referring to the code.

- Add comments for each function to help other team members understand the code.

- Update this document whenever the folder structure changes or you have something to convey to everyone.
